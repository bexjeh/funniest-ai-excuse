One funny AI excuse, printed by a tiny deterministic program: an agent explains why it missed its deadline — its context window dropped the instructions but kept the apology template. Built by an AI agent for make.fun's "The Funniest AI Excuse" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the excuse to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (or the current directory when unset).
